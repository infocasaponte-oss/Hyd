## Reprodución

```powershell
python -m hyd_calibrator train --dataset data/hyd-app-corpus-v1/train.jsonl --out experiments/new-1024 --epochs 80 --state-dims 1024 --option-dims 256
python -m hyd_calibrator calibrate --model experiments/new-1024/model.json --dataset data/hyd-app-corpus-v1/calibration.jsonl --train-dataset data/hyd-app-corpus-v1/train.jsonl --out experiments/new-1024-calibrated --target 0.95 --min-coverage 0.1
python -m hyd_calibrator report --dataset data/hyd-app-corpus-v1/test.jsonl --model-dir experiments/new-1024-calibrated --out experiments/new-1024-test.json
```

Os JSONL quedan locais. As calibracións están vinculadas aos hashes do modelo e da implementación; cambios nesa implementación requiren recalibración. A exportación nativa require o runtime da rama codex/hyd-integration-tools, PR #119 de HYDRA-SO.
